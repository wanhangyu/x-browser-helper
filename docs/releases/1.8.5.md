## 本次更新

- **统一设置入口**：面板右下角改为“⚙ 设置”，集中管理显示与阅读、热度榜、外观、数据与布局。
- **更容易找到开关**：粉丝显示、额外作者简介与关注按钮位于设置第一组；重置布局移入“数据与布局”。
- **内容页面更简洁**：热度页移除齿轮和内嵌设置，账号页专注查看与搜索账号。
- **适配 X 深色模式**：粉丝与热度标签自动跟随浅色、纯黑或深蓝背景，使用更清晰的数字和柔和底色；助手面板仍可独立选择配色。
- **保留操作状态**：进入设置再返回不会丢失未保存的搜索草稿；已有固定搜索、显示设置和布局记忆继续保留。

## 下载与更新

下载附件 **`x-browser-helper-1.8.5.zip`**，解压后加载直接包含 `manifest.json` 的 `x-browser-helper` 文件夹。

已安装用户覆盖原安装目录文件，点击扩展的“重新加载”，再刷新 X 即可；无需卸载。已在本地体验过 1.8.5 的用户无需重复安装。

SHA-256 校验值见同名 `.sha256` 附件。GitHub 自动生成的 Source code 为开发源码，普通使用者请选择安装附件。

## 验证

自动流程检查核心逻辑、翻译协议、热度、阅读、关注模拟、布局、统一设置和打包完整性。明暗配色回归覆盖纯黑、深蓝及浅色背景，粉丝与热度标签文字对比度达到 4.5:1。测试使用合成账号与隔离浏览器，不使用个人登录信息。

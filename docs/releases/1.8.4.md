# X 浏览助手 1.8.4

免费开源，MIT 许可。适用于桌面 Chrome / Microsoft Edge。

## 下载与安装

下载本页附件 `x-browser-helper-1.8.4.zip`，解压后在扩展管理页开启开发者模式，加载其中直接包含 `manifest.json` 的 `x-browser-helper` 文件夹。

已有用户将新文件覆盖到原安装目录，点击“重新加载”，再刷新 X；保留原目录和设置，无需卸载。SHA-256 校验值见同名 `.sha256` 附件。GitHub 自动生成的 Source code 是开发源码，普通使用者选择上面的安装包即可。

## 本次更新

- 翻译 Key 默认仅本次浏览器会话使用；可明确勾选“在此浏览器记住 Key”。旧版未明确选择的持久 Key 自动转为当前会话使用。
- 重启浏览器、重载或更新扩展后，会话 Key 清除；设置页提示重新填写。长期保存的 Key 不云端同步，本地存储不是加密保险箱。
- 展示将申请的翻译域名和已授权站点，支持逐个撤销；撤销当前服务后停用在线翻译并清除 Key。
- 统一平均热度与引用帖指标的提示，说明发布以来平均值、非实时新增。
- 增加安全报告说明、依赖更新检查和可重复的正式发布流程。

## 热度口径

平均热度为发布以来累计浏览量除以发布小时数；不足 6 分钟按 6 分钟计算。本页榜单只包含已加载帖子，不代表全 X 排行。

## 验证

发布流程运行核心、翻译协议、隔离浏览器回归和白名单打包。自动测试使用合成账号与响应，不代表所有真实 X 界面和外部翻译服务均已实测。

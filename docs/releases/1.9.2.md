## 来源与致谢

本轮图片增强、长图阅读、相关样式与内置过滤规则，主要复用并改编自 **[IcyCat 的 X Viral Monitor（X 爆款监测）](https://github.com/Icy-Cat/x-viral-monitor)**。Markdown 复制与规则结构参考其设计，使用本项目数据通道适配重写。感谢原作者公开源码。

简介翻译与手动关注等组件另适配自 **[yiren-ai/xpandmax](https://github.com/yiren-ai/xpandmax)**。我们在开源项目基础上做界面整合、设置简化、功能取舍和稳定性适配。原始 MIT 许可随安装包保留，具体来源提交与文件见 [第三方代码说明](https://github.com/wanhangyu/x-browser-helper/blob/v1.9.2/THIRD_PARTY_NOTICES.md)。

## 本次更新

- **书签数**：在原生书签按钮旁显示已读取计数，未知时显示“—”。
- **图片与长图**：支持缩放、拖动、快捷键与长图纵向阅读；改善持续页面更新和多图切换时的初始化与目标同步。
- **可选复制格式**：分享菜单提供一个复制入口，设置里选择纯正文或带出处 Markdown，并可关闭 Markdown 图片链接；默认保留原复制行为。
- **可选内容过滤**：中文原因提示、悬停匹配依据、当前已加载帖子的折叠与手动展开统计，支持自定义关键词和保留账号。
- **可选远程规则**：本人按域名授权后，从原项目固定公开 JSON 地址更新；失败保留有效规则，不执行远程脚本。内容过滤与远程更新默认关闭。
- **保持简洁**：已移除感谢星图；保留粉丝与热度顺序、统一设置、原有搜索及面板位置记忆。

## 下载与更新

下载附件 **x-browser-helper-1.9.2.zip**，解压后加载其中直接包含 manifest.json 的 x-browser-helper 文件夹。校验值见同名 .sha256 附件。

已安装用户覆盖原安装目录，点击扩展的“重新加载”，再刷新 X，无需卸载。本地已使用 1.9.2 的用户无需为此次 GitHub 发布重复安装。

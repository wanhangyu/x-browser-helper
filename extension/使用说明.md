# X 浏览助手 1.8.5

## 安装与更新

在 Chrome 或 Edge 的扩展管理页开启开发者模式，加载本文件夹（应能看到 manifest.json），随后刷新 X。已经安装时覆盖原文件夹，点“重新加载”并刷新 X，无须卸载。

## 使用

粉丝数显示在头部发布时间后；额外作者简介与关注按钮默认关闭，在助手右下角“设置 → 显示与阅读”中开启。页面侧边的“X 助手”标签打开热度榜、账号和固定搜索工作台。点击排名定位帖子。榜单仅统计当前已加载内容；平均流速是累计浏览量除以发布时长，不是最近一小时新增。

工具栏弹窗提供阅读开关及简介翻译设置。默认尝试本机翻译；可选 Google 免 Key 或自定义接口，保存后测试。选择在线服务后简介会发给该服务商，自定义服务可能收费。不支持或失败时保留原文。

API Key 默认仅本次会话保存，重启浏览器、重载或更新扩展后需重新填写。勾选“在此浏览器记住 Key”才会长期保存，本地存储不是加密保险箱。旧版 Key 会迁入当前会话，设置不云端同步。

翻译设置页可查看待申请域名和已授权站点，支持逐个撤销；撤销当前服务后恢复本机翻译并清除 Key。可选任意 HTTPS 域名是为了支持自填接口，并不默认获得所有网站的权限。

关注只在本人点击后复用 X 原生操作，等待结果确认，不批量自动关注。未知数据不补成 0，页面或接口变化可能影响兼容性。

## 简洁布局

热度默认紧跟粉丝数，粉丝数紧跟头部发布时间。右下角“设置”统一管理显示与阅读、热度榜、外观、数据与布局；进入“热度榜设置”可修改筛选、显示列及标签位置。原有固定搜索、分组与置顶保持可用。重置布局已移入“设置 → 数据与布局”。

粉丝和热度标签自动跟随 X 的浅色、纯黑或深蓝背景；助手面板可在“设置 → 外观”独立选择暖白、深色或跟随 X。

点面板标题栏减号，助手收至最近的屏幕边缘；点击侧边“X 助手”标签恢复收起前的位置和大小。拖动标题可移动，靠近左右边缘自动对齐。底部罗盘和小标题折叠形态已移除，鼠标移出或悬停不会改变收放状态。

缩小后的“X 助手”标签支持自由拖动，靠近屏幕左右边缘时自动吸附。标签的位置和吸附侧会保存在本机，再次收起和刷新后保留；拖动不会展开，轻点才展开，完整面板的位置和大小独立记忆。

面板和缩小标签贴边时都会避开页面滚动条并留出间距；调整浏览器窗口或滚动条出现时会自动重新校正。

## 1.9.2 新增功能

- 设置 → 图片与分享：书签数、图片增强、长图阅读、Markdown 开关。
- 推文分享菜单 → 复制为 Markdown。
- 打开图片：Ctrl＋滚轮缩放，放大后可拖动，双击切换缩放，0 复位。长图自动纵向滚动。
- 设置 → 内容过滤：开启折叠、选择强度、填写自定义规则与保留账号。默认关闭，单条内容可以展开。
- 自定义规则一行一条，例如“正文:抽奖引流”“作者:example”“简介:接广告”；不加前缀时匹配正文，按字面匹配。
- 远程规则默认关闭，点击专用入口授权后更新；来源为 IcyCat 的公开 GitHub JSON，不上传浏览内容。

图片与长图、内置规则改编自 IcyCat / X Viral Monitor。原项目链接与 MIT 许可随包保存在 THIRD_PARTY_NOTICES.txt 和 third-party 目录。


## 复制格式与过滤提示

- 设置 → 图片与分享 → 复制格式：选择纯正文或带出处 Markdown。Markdown 可选择是否包含图片链接，纯正文不会附加作者、出处或图片。分享菜单按选择显示“复制正文”或“复制为 Markdown”。
- 复制格式默认沿用旧版带出处和图片的 Markdown，修改后立即保存。
- 内容过滤标题显示当前已加载帖子里的折叠条数，展开后能看到手动展开数量。页面滚动后，统计随 X 当前保留的帖子变化，不是历史累计数量。
- 折叠提示采用“疑似引流推广”“疑似成人内容”“命中自定义关键词”等中文说明；悬停原因可看匹配字段或自定义关键词。规则可能误判，可显示这条、加入保留账号，或关闭过滤。

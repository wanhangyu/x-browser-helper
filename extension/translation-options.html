X 浏览助手

简介翻译

浏览器的本地翻译能力可能不同。如果无法启用，可以选择免 Key 在线翻译，或接入自己的翻译 API。

简介在本机处理，需要浏览器支持语言检测和中文翻译模型。保存此选项会清除已存的 API 配置。

无需填写 Key。开启后，待翻译的简介会发送给 Google。此入口并非有正式服务保障的 Google Cloud API，可能限流或失效，不保证长期免费。保存此选项会清除已存的自定义 API 配置。

开启后，待翻译的简介会发送给你填写的服务商。服务商可能收费，请先了解其价格和隐私政策。配置仅保存在此浏览器，不会云端同步。

填写完整的 HTTPS Chat Completions 地址，包含路径。并非所有 API 都兼容此协议。 服务商不需要 Key 时可留空；请勿使用 X 的登录令牌。 默认仅本次会话使用；重启浏览器、重载或更新扩展后需重新填写。勾选后会保存在本地，非加密保险箱，不会云端同步。

Anthropic 协议会携带允许浏览器直连的请求头，Key 会发送到你填写的接口域名。请确认该域名由你信任的服务商控制。

翻译站点授权

保存在线翻译时，仅请求对应 HTTPS 域名。为支持你自己的接口地址，插件声明可选域名范围，并不默认获得所有网站的访问权。

    撤销当前翻译域名后会停用在线翻译并清除 Key；可重新保存设置再授权。

    测试会发送一句虚构示例“I build useful tools.”，自定义 API 可能产生少量费用。

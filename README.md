# X 浏览助手

在 X 上看账号、看热度、找内容。面向桌面 Chrome / Edge 的 Manifest V3 扩展，由 [万航宇](https://github.com/wanhangyu) 独立维护。

当前版本：**1.6.1**。无需订阅或激活，扩展运行时不依赖第三方 JavaScript 包。

## 功能

| 功能 | 用法 |
| --- | --- |
| 账号信息 | 在作者附近显示粉丝数和简介，点击展开全文与账号自填所在地 |
| 帖子热度 | 显示发布以来的平均浏览量/小时；悬停查看互动数据与参考指数 |
| 本页热点榜 | 按平均热度排序当前已加载帖子，点击榜单定位、高亮并显示连线 |
| 内容筛选 | 可按平均热度、累计浏览量和发布时间筛选，提供可调整的预设 |
| 固定搜索 | 保存高级搜索，按当前日期生成最近 N 天条件，支持分组与置顶 |
| 简介翻译 | 默认尝试浏览器本机中文翻译，可选 Google 免 Key 或自己的兼容接口 |
| 手动关注 | 本人点击后复用 X 原生菜单，确认结果后显示已关注或已申请 |
| 阅读布局 | 独立隐藏左右栏或通知数字，面板可拖动、折叠和调整大小 |

平均热度是**累计浏览量 ÷ 发布时长**，不是最近一小时的实时新增。本页榜单只包括当前页面已经加载的帖子，不是全 X 排行榜。数字未知时不补成 0；数据与页面结构变化可能影响显示。

## 安装和更新

1. 下载仓库 ZIP 并解压，或克隆本仓库。
2. 打开 `chrome://extensions` 或 `edge://extensions`，开启开发者模式。
3. 点击“加载已解压的扩展程序”，选择本仓库的 **extension** 文件夹。
4. 刷新 X 页面；点击页面中的罗盘按钮打开工作台。

已安装的用户覆盖原目录文件后，点击扩展的“重新加载”，再刷新 X 即可。不要卸载，避免删除本地搜索和设置。打包 ZIP 解压后，选择包含 `manifest.json` 的文件夹。

## 简介翻译

默认使用浏览器本机能力。浏览器不支持或模型未就绪时保留原文；首次使用可能需要在展开的简介中点击启用并下载语言包。中文与中英混合简介默认保持原文。

打开浏览器工具栏中的插件图标，进入“简介翻译设置与接口测试”，可选择：

- Google 在线翻译：无需 Key，可能限流或失效，没有长期服务保证。
- Chat Completions、Anthropic Messages 或 Gemini 原生接口：填写自己的 HTTPS 地址、模型和 Key，服务商可能收费。

选择在线服务后，屏幕内待翻译的简介会发送到所选服务商。保存时只申请该服务域名的访问权限；随后可用虚构示例测试连接。译文可切换原文，设置变更会清除旧译文。详见 [隐私说明](PRIVACY.md)。

## 开发与验证

需要 Node.js 22+、Python 3.9+。Playwright 仅用于开发测试，不进入插件运行目录。

```sh
npm ci --ignore-scripts
npm run build
npm test
npx playwright install chromium
npm run test:browser
npm run package
```

Linux 首次准备浏览器时可使用 `npx playwright install --with-deps chromium`。也可通过环境变量 `X_HELPER_BROWSER_PATH` 指向兼容的 Chrome / Edge 可执行文件；`HEADED=1` 使用可见测试窗口。测试创建独立配置，不读取日常浏览器的登录信息。

安装包和 SHA-256 校验文件生成在 `dist/`；测试截图位于 `artifacts/screenshots/`。这些输出不纳入源码提交。

```text
extension/   实际扩展与第三方许可
tests/       合成数据、核心测试与独立浏览器验收
scripts/     构建、检查、测试和白名单打包
.github/     GitHub Actions 检查
```

`content.bundle.js` 由 `core.js`、`dom.js` 和 `content.js` 按顺序合成，修改后运行 `npm run build`。`npm test` 会检查合成文件、清单、权限、版本、许可证与核心行为。

## 当前验证范围

1.6.1 已在作者实际登录的 X 主页确认热度标签、热点榜和定位连线恢复。自动浏览器测试使用虚构页面与响应，覆盖真实时间链接结构、引用隔离、普通展示容器、广告标记、筛选、布局、固定搜索、翻译界面和原生关注模拟闭环。

模拟通过不代表所有真实 X 界面、浏览器本机语言模型或第三方模型均已实测。自定义翻译服务需要使用者自行测试自己的模型与额度；关注测试不会对真实账号执行操作。
